PIPELINE CYPRESS GITLAB

Esse tutorial tem como objetivo mostrar de maneira básica como se criar uma pipeline para o sistema de armazenamento de código Gitlab. Para entender esse tutorial, realizei uma divisão para entendermos um pouco mais sobre o funcionamento de uma pipeline e a partir desse conhecimento inicial conhecermos como criar a pipeline para testes automatizados com o Cypress. Básico sobre pipelines Pipeline é um componente de integração, entrega e implementação contínua (CI/CD). Cada pipeline é composta por jobs que definem o que será feito pela determinada pipeline, essa pode ser de compilação de um projeto, teste ou integração. Uma pipeline criada corretamente simplifica a forma como o código é integrado e com uso de fluxos automatizados faz com que se diminua a chance de erro humano.
