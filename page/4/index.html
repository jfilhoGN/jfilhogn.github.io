PRÁTICA DE CODE REVIEW E QUALIDADE DE SOFTWARE

Sempre que falamos de Qualidade de Software, logo pensamos em um conjunto de práticas que visa uma entrega de software contendo características como eficiência, corretude e que tenha padrões que facilite manutenções. Uma prática utilizada para garantir essas características é o Code Review. O code review é uma análise minuciosa do código de uma aplicação, software ou uma solução, onde seu objetivo não é somente encontrar erros, mas também a falta de padrão, nomes incorretos de variáveis e possíveis melhorias na lógica do desenvolvimento.
